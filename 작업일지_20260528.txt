■ 작업 개요
  PROGRESS.md에 기록된 미완료 항목 전체 구현 및 버그 수정

------------------------------------------------------------
1. 총 공수 실시간 합계 표시
------------------------------------------------------------
- 파일: index.html, mobile.html
- 인력 섹션 헤더에 "합계 N명" 배지 추가
- 공수 선택(0.5/1.0) 시 자동으로 합계 갱신
- 행 삭제 시에도 자동 재계산
- 관련 함수: updateManTotal() / updateManTotalMobile()

------------------------------------------------------------
2. 전날 인력·장비 복사 버튼
------------------------------------------------------------
- 파일: index.html, mobile.html
- 인력 섹션 헤더 우측에 "⏮ 전날 복사" 버튼 추가
- 현재 선택 날짜의 전날 저장 일보에서 인력·장비 행 복사
- 관련 함수: copyPrevDay() / copyPrevDayMobile()

------------------------------------------------------------
3. 작업내용 템플릿 저장/불러오기
------------------------------------------------------------
- 파일: index.html, mobile.html
- 작업내용/계획 섹션 헤더에 "💾 저장" "📂 불러오기" 버튼 추가
- 템플릿 이름 지정 후 localStorage에 저장
- 드롭다운 선택 후 적용/삭제 가능
- 저장 키: work_templates
- 관련 함수: saveWorkTemplate() / toggleTplModal() / applyTemplate() / deleteTemplate()
  (모바일은 각각 Mobile 접미사)

------------------------------------------------------------
4. 전체 데이터 백업/복원
------------------------------------------------------------
- 파일: index.html, mobile.html
- "💾 전체 백업": 모든 localStorage 키를 단일 JSON 파일로 다운로드
  (projects, companies, jobs, names, equip_names, supervisors,
   daily_logs, unit_prices, work_templates)
- "📂 전체 복원": 백업 JSON 파일을 불러와 전체 데이터 복원 후 페이지 리로드
- 모바일은 Web Share API로 공유 지원
- 파일명: 공사일지_백업_YYYY-MM-DD.json
- 관련 함수: backupAll() / restoreAll()

------------------------------------------------------------
5. 현장 사진 첨부
------------------------------------------------------------
- 파일: mobile.html
- 자재 반입 현황과 작업내용 섹션 사이에 "📷 현장 사진" 섹션 추가
- 카메라 촬영 또는 갤러리 선택 (input[type=file] capture)
- 최대 6장, Canvas를 이용해 800px 이하로 자동 압축 (JPEG 72%)
- 썸네일 그리드 표시, 개별 삭제 버튼
- 임시저장/내보내기 시 photos 배열로 일보 데이터에 포함
- PDF 인쇄 시 일보 하단에 3열 그리드로 출력
- 관련 함수: addPhotos() / renderPhotos() / removePhoto()

------------------------------------------------------------
6. 현장 계산기 모달 내장 (tools.html 삭제)
------------------------------------------------------------
- 파일: index.html, mobile.html
- tools.html 파일 삭제
- PC(index.html): 헤더 "🔧 계산기" 버튼 → 중앙 모달로 열림
- 모바일(mobile.html): 헤더 버튼 + 상단 빠른 이동 카드 → 바텀 시트 모달로 열림
- 파일 간 이동 없이 일보 작성 화면에서 바로 사용 가능
  (모바일 Chrome의 file:// 보안 제한 문제 해결)

- 계산기 탭 구성:
  ① 🌳 수목 중량 — 근원직경/흉고직경 입력 → 근분 직경·깊이·중량·크레인 용량 계산
      공식: 근분직경 = 근원직경×4 (흉고×4.5), 깊이 = 직경×0.7
      부피 = 반구 (2/3)πr³, 수체 25%, 안전율 선택
  ② 📐 면적 계산 — 사각·원·삼각·사다리꼴·타원 5가지 형태
      m² ↔ 평 ↔ ha 단위 변환 포함
  ③ 🌱 근분 규격표 — 근원직경/흉고직경별 근분 직경·깊이·중량 참고표

- 관련 함수: openCalc() / closeCalc() / showCalcTab() / calcTreeM()
             calcAreaM() / convertAreaM() / buildCRefTables() 등

------------------------------------------------------------
7. 타원형 면적 계산 버그 수정
------------------------------------------------------------
- 파일: index.html, mobile.html (계산기 모달)
- 문제: 입력 라벨이 "반경"으로 되어 있어 전체 길이 입력 시 4배 오차 발생
- 수정: 입력 라벨 → "장축 전체 길이 / 단축 전체 길이"
        공식 변경: π×ra×rb → π×(장축/2)×(단축/2)
- 예시: 가로 10m × 세로 6m 타원 = 47.12㎡ (수정 전 188.5㎡)

------------------------------------------------------------

  mobile.html: 🔧 현장 계산기 모달, 현장 사진, 인력 합계 배지, 템플릿, 백업/복원 설명 추가

■ localStorage 키 구성
============================================================
  projects        — 공사명 목록
  companies       — 시공사 목록
  jobs            — 직종 목록 (기본: 직영, 용역, 특수인부)
  names           — 성명 목록
  equip_names     — 장비명 목록 (기본: 굴삭기, 지게차, 카고크레인, 화물트럭)
  supervisors     — 현장대리인 목록
  daily_logs      — 일보 데이터 { "공사명||날짜": { ...데이터, locked, photos } }
  unit_prices     — 정산 단가 { man: {성명:단가}, eq: {장비명:단가} }
  work_templates  — 작업내용 템플릿 [{ name, work, plan }]
