# 사진대지 Android APK 빌드 방법

## 사전 준비
- Node.js 설치 확인: `node -v`
- Android Studio 설치 (약 8GB)
- JDK 17 이상

## 빌드 순서

### 1단계 — 패키지 설치
```
cd C:\Users\USER\AI-Founders\construction-docs\사진대지-apk
npm install
```

### 2단계 — Android 프로젝트 추가 (최초 1회)
```
npx cap add android
```

### 3단계 — 웹 파일 동기화
```
npx cap sync android
```

### 4단계 — Android Studio에서 빌드
```
npx cap open android
```
Android Studio 열리면:
- Build → Generate Signed APK (서명 APK) 또는
- Build → Build Bundle(s) / APK(s) → Build APK(s) (디버그 APK)

### 디버그 APK 위치
```
android/app/build/outputs/apk/debug/app-debug.apk
```

## 설치 방법 (사이드로딩)
1. 카카오톡/이메일로 APK 파일 전송
2. Android 기기에서 파일 실행
3. "알 수 없는 앱 설치 허용" 설정 → 설치

## 업데이트 시
`www/index.html` 수정 후 → `npx cap sync android` → Android Studio에서 재빌드
