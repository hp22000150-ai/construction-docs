사진 추가
도움말
📋 입력/편집 탭
• 사진 슬롯 탭 → 카메라로 찍기 / 갤러리에서 선택
• 사진 추가 시 촬영일자 자동 입력 (수정 가능)
• 사진 위 ↻ 버튼으로 90° 회전
• 페이지 헤더의 숫자(0/3)로 입력 진행 상황 확인
• 상단 2컷/3컷 버튼으로 전체 페이지 구성 변경
• 하단 💾 내보내기 → .json 파일 PC로 전송

🖼️ 갤러리 탭
• 촬영한 원본 사진 보관 (초기화해도 유지)
• ⬇️ 전체 저장 → 모든 원본 순차 다운로드
• 🗑️ 전체 삭제 → 갤러리 사진만 삭제
• 사진 탭 → 전체화면, ⬇️ 저장으로 개별 다운로드

⚙️ 설정 탭
• 공사명·시공회사·공사위치·발주처·작성일 입력
• 공사위치 옆 📍 버튼으로 GPS 위치 자동 입력
• PC에서 .json 파일 열기 → 인쇄·PDF 저장 가능
• ↺ 초기화 → 작업 데이터 삭제 (갤러리 사진 유지)

💡 사용 팁
• 입력 내용은 자동저장됩니다
