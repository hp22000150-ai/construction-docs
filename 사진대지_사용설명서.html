앱 소개

공사사진대지는 공사 현장에서 촬영한 사진을 체계적으로 정리하고, PC에서 A4 사진대지 양식으로 출력하거나 PDF로 저장할 수 있는 앱입니다.

Android APK 설치
스마트폰
1
APK 파일 받기 카카오톡 또는 이메일로 전달받은 사진대지_v0602_7.apk 파일을 저장합니다.
2
출처를 알 수 없는 앱 허용 설정 → 보안 → 출처를 알 수 없는 앱 설치 허용 (또는 파일 실행 시 팝업에서 허용)
3
APK 파일 실행 내 파일 앱 → 다운로드 폴더 → APK 파일 탭하여 설치
4
설치 완료 홈 화면 또는 앱 서랍에서 현장 사진대지 아이콘을 탭하여 실행
💡 갤럭시 사용자: 내 파일 앱에서 APK 파일을 꾹 누른 후 ⋮ 더보기 → 홈 화면에 추가 하면 바탕화면 바로가기가 생깁니다.

모바일 앱 사용법
현장 촬영

입력/편집 탭

1
사진 추가 사진 슬롯(전·중·완)을 탭 → 카메라로 찍기 또는 갤러리에서 선택
2
날짜 · 설명 입력 촬영일자는 사진 추가 시 자동 입력됩니다. 수정 가능하며 사진 설명도 입력하세요.
3
페이지 추가 공종이 여러 개인 경우 + 페이지 추가 버튼으로 페이지를 늘립니다.
4
내보내기 하단 💾 내보내기 (.json) 버튼 → 다운로드 폴더에 파일이 저장됩니다.

설정 탭

공사명·시공회사·공사위치·발주처·작성일을 입력합니다. 공사위치 옆 📍 버튼으로 GPS 자동 입력도 가능합니다.

갤러리 탭

촬영한 원본 사진이 보관됩니다. 전체 저장·삭제, 선택 저장·삭제, 개별 저장이 가능합니다. 초기화해도 갤러리 사진은 유지됩니다.

💡 2컷 / 3컷: 상단 버튼으로 전·완료(2장) 또는 전·중·완료(3장) 구성을 전체 변경할 수 있습니다.
4
PC 뷰어(EXE) 사용법
인쇄 · PDF
1
공사사진대지.exe 실행 전달받은 공사사진대지.exe 파일을 더블클릭합니다. 설치 불필요.
2
파일 불러오기 상단 📂 불러오기 버튼 → 모바일에서 전송받은 .json 파일 선택
3
표지 정보 확인 공사명·시공회사·공사위치·발주처·작성일이 자동으로 채워집니다. 필요 시 수정 가능.
4
인쇄 또는 PDF 저장 상단 🖨️ 인쇄 버튼 → 프린터 선택 또는 PDF로 저장 선택
💡 사진이 잘릴 경우: 상단 꽉채움 / 전체보기 토글로 사진 표시 방식을 변경하세요.
5
모바일 → PC 파일 전송
파일 주고받기

모바일 앱에서 내보낸 .json 파일을 PC로 전송하는 방법입니다.

💬
카카오톡 나에게 보내기 가장 빠름. 내보내기 → 카카오톡 선택 → 나에게 → PC 카카오톡에서 다운로드
📧
이메일 내보내기 → 이메일 앱 선택 → 파일 첨부 전송 → PC에서 다운로드
☁️
클라우드 구글 드라이브·원드라이브 앱으로 공유 → PC 브라우저에서 다운로드
🔌
USB 케이블 폰과 PC 연결 → 파일 전송 모드 → 다운로드 폴더에서 직접 복사
