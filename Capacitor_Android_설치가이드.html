📱 공사일지 앱 — Android 배포 가이드

작성일: 2026-05  |  대상: 공사일지 V 0.530.1

📋 개요

현재 HTML 기반의 공사일지 앱을 Capacitor를 사용해 Android APK로 패키징합니다.
APK 파일을 카카오톡/이메일로 공유하면 Play Store 등록 없이 바로 설치 가능합니다.

항목내용
배포 방식APK 직접 설치 (사이드로딩)
앱스토어 등록불필요
코드 재사용기존 HTML/JS 그대로 사용
설치 용량Android Studio 약 8~10GB

🛠 1단계 — 사전 준비

① Node.js 확인

1 명령 프롬프트(cmd)에서 확인:
node -v
버전이 표시되면 OK. 없으면 nodejs.org 에서 설치.

② Android Studio 설치

1 developer.android.com/studio 접속 → 다운로드
2 설치파일 실행 → 기본 설정(Next) → 완료
3 첫 실행 시 Android SDK 자동 설치 (시간 소요)
⚠️ 설치 경로에 한글/공백 없어야 합니다.

③ 환경변수 설정 (Android Studio 설치 후)

시스템 환경변수에 ANDROID_HOME 추가:

변수명값 (기본 경로)
ANDROID_HOMEC:\Users\[사용자명]\AppData\Local\Android\Sdk

Path에도 추가:

%ANDROID_HOME%\platform-tools

📦 2단계 — Capacitor 설치 및 설정

1 프로젝트 폴더에서 Capacitor 설치:
cd C:\Users\USER\AI-Founders\construction-docs npm install @capacitor/core @capacitor/cli @capacitor/android
2 Capacitor 초기화:
npx cap init 공사일지 com.construction.dailylog --web-dir .
3 Android 플랫폼 추가:
npx cap add android
4 웹 파일 동기화:
npx cap sync android

🔨 3단계 — APK 빌드

1 Android Studio에서 프로젝트 열기:
npx cap open android
2 Android Studio 메뉴: Build → Build Bundle(s)/APK(s) → Build APK(s)
3 빌드 완료 후 APK 위치:
android\app\build\outputs\apk\debug\app-debug.apk

📲 4단계 — 설치 (현장 직원)

1 APK 파일을 카카오톡 또는 이메일로 전송
2 받는 사람 폰: 설정 → 보안 → "알 수 없는 출처 앱 허용" 체크
3 다운로드된 APK 탭 → 설치

🔄 앱 업데이트 방법

코드 수정 후 아래 순서로 새 APK 배포:

npx cap sync android

→ Android Studio에서 다시 Build APK → 새 APK 파일 공유

📌 참고사항

  • 파일시스템 접근이 필요하면 @capacitor/filesystem 플러그인 추가
  • 카메라 기능은 @capacitor/camera 플러그인으로 더 안정적으로 동작
  • Google Play Store 등록 원할 경우 서명된 APK(keystore) 별도 생성 필요
