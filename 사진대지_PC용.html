도움말

  1. 공사명 / 업체명 / 작성일 표지에 직접 입력 (작성일은 날짜 선택기)
  2. 2컷 / 3컷 토글 : 전·완료(2장) 또는 전·중·완료(3장) 전체 적용
  3. 📷 사진 한번에 올리기 : 여러 장 선택 →
      • 순서대로 바로 삽입 : 선택 순서 그대로 삽입
      • 순서 지정 후 삽입 : 썸네일 클릭으로 순서 지정
  4. 사진 칸 클릭 → 사진 개별 업로드 / 사진 위 ✕로 삭제 / ↻로 회전
  5. 촬영일자 : 월일만 입력 (312 → 2026-03-12, 0312 → 2026-03-12)
  6. 사진 설명 입력 후 Enter → 자동저장
  7. 공종 추가 시 하단 + 페이지 추가 버튼 클릭
  8. 💾 저장 : 작업 파일(.json)로 보관
  9. 📂 불러오기 : 저장된 파일 이어서 편집
  10. 🖨️ 인쇄 : 출력 또는 PDF 저장
  11. 사진이 잘릴 경우 꽉채움 / 전체보기 토글
  12. ↺ 초기화 : 모든 내용 및 자동저장 데이터 완전 삭제

※ 입력 내용은 자동저장됩니다
※ 사진은 자동 압축되어 용량이 줄어듭니다
※ .json 파일 공유 시 원본 사진 불필요
