하단에 📦 데이터 전송 — 기간·월·전체 선택 후 PC 정산용 JSON 파일 전송.

📅 기본 정보
작성일 — 달력에서 날짜 선택. 저장된 날짜는 초록 점(●) 표시.
해당 날짜에 저장된 일보가 있으면 📂 불러오기 버튼 활성화.
날씨·기온 — 📍 버튼으로 GPS 기반 자동 입력.
공사명·시공사 — 기본설정에서 등록 후 드롭다운 선택.

👷 인력 투입
직종·성명 드롭다운 선택. 공수 숫자 입력 (0.5/1.0 자동완성 제공).
합계 공수 실시간 배지 표시. ⏮ 전날 복사 버튼으로 전날 인력·장비 불러오기.

🚜 장비 투입
장비명·기사명·시간 입력. 금액(원)란에 직접 금액 입력 시 정산 시 단가 계산 대신 해당 금액 사용.

📦 자재 반입
품명·규격·단위·수량·거래처 입력.

📷 현장 사진
최대 6장. 자동 압축 저장. PDF 인쇄 시 함께 출력.

📝 작업내용 템플릿
💾 저장 버튼으로 현재 작업내용 저장 / 📂 버튼으로 저장된 템플릿 적용.

하단 버튼
💾 임시저장 — 월별로 저장. 언제든 수정 가능.
📤 내보내기 — 하루치 최종 제출 + 잠금. 카카오톡·이메일 공유.
🖨️ PDF 인쇄 — 작업일지 + 사진 인쇄/PDF 저장.

🔄 재작성
잠금 후 수정 필요 시 → 🔄 재작성 → 사유 입력 → 수정 후 재제출. 이력 자동 기록.
