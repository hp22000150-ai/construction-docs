🚀 처음 시작하기
1. ⚙️ 설정 탭에서 공사명·시공사·직종·성명·장비명 등록
2. 📋 일보 탭에서 날짜 선택 후 인력·장비 입력
3. 📷 사진 탭에서 현장 사진 추가
4. 일보 탭 하단 📤 통합 내보내기로 파일 저장
5. PC에서 통합-PC.html로 열어 인쇄

📋 일보 탭
• 달력에서 날짜 선택 — 저장된 날짜는 초록 점(●) 표시
• 저장된 일보 있으면 📂 불러오기 버튼 활성화
• 📍자동 버튼으로 GPS 기반 날씨·기온 자동 입력
• ⏮ 전날 버튼으로 전날 인력·장비 그대로 복사
• 공수: 0.5 / 1.0 버튼 빠른 선택, 또는 직접 입력칸에 숫자 입력
• 💾 작업내용 저장 → 자주 쓰는 내용 템플릿으로 보관
• 💾 임시저장 — 언제든 수정 가능
• 📤 통합 내보내기 — 일보 + 사진 한 파일로 저장 (잠금됨)

📷 사진 탭
• 사진 슬롯 탭 → 카메라로 찍기 / 갤러리에서 선택
• 사진 추가 시 촬영일자 자동 입력 (수정 가능)
• 사진 위 ↻ 버튼으로 90° 회전
• 사진 위 ✕ 버튼으로 해당 사진 삭제
• 페이지 헤더 ✕ 삭제 버튼으로 페이지 전체 삭제
• 페이지 헤더 공종명란에 공종 입력 (예: 터파기, 철근배근)
• 상단 2컷/3컷 버튼으로 전체 페이지 레이아웃 변경
• + 페이지 추가로 공종별 페이지 구분

🖼️ 갤러리 탭
• 촬영한 원본 사진 보관 (사진 탭 초기화해도 유지됨)
• ☑️ 선택 → 탭으로 사진 선택 후 ⬇️ 저장 / 🗑️ 삭제
• ⬇️ 전체 저장 → 원본 사진 전체 순차 다운로드
• 🗑️ 전체 삭제 → 갤러리 원본만 전체 삭제 (확인 필요)
• 사진 슬롯에 이미 사진이 있으면 교체 시 덮어쓰기 확인 표시

⚙️ 설정 탭
• 공사명·시공사·직종·성명·장비명·현장대리인 목록 추가·삭제
• 공사일보 앱과 목록 공유 — 한쪽에서 등록하면 양쪽에서 사용 가능
• 공사위치 옆 📍 버튼으로 GPS 주소 자동 입력
• 💾 전체 백업 — 모든 데이터 파일로 저장
• 📂 전체 복원 — 백업 파일로 데이터 복원
