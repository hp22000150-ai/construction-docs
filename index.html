기온 📍자동
버튼 클릭 시 GPS 위치 기반으로 최저·최고 기온과 날씨를 자동 입력합니다. 브라우저 위치 권한 허용 및 인터넷 연결 필요.

자동완성 목록 관리
직종·성명·장비명을 미리 등록해두는 곳입니다. 등록하면 인력·장비 입력 행의 드롭다운에 자동으로 나타납니다.
• 직종 기본값: 직영, 용역, 특수인부
• 장비명 기본값: 굴삭기, 지게차, 카고크레인, 화물트럭

인력 투입 현황
• 직종·성명: 드롭다운 선택 (목록 관리에서 사전 등록 필요)
• 공수: 0.5 = 반일, 1.0 = 전일
• 누계: 📄 일보 생성하기 클릭 시 과거 일보 기록을 합산하여 자동 계산
• 헤더의 합계 N명 배지: 공수 선택 시 실시간 갱신

⏮ 전날 복사
인력 섹션 우측 버튼 클릭 시 전날 인력·장비 데이터를 복사합니다.

장비 투입 현황
• 장비명: 드롭다운 선택 / 규격은 직접 입력 (예: 0.6㎥, 5톤)
• 금일: 0.5 = 반일, 1.0 = 전일 / 누계: 자동 계산

자재 반입 현황
품명·규격·단위·수량·거래처·비고 순으로 입력합니다.

작업내용 템플릿
• 💾 저장 — 현재 작업내용·계획을 이름 붙여 저장
• 📂 불러오기 — 저장된 템플릿 선택 후 적용

버튼 안내
• 📄 일보 생성하기 — 미리보기 생성 + 데이터 저장 + 누계 계산
• 📤 내보내기 — 최종 제출 (잠금) + JSON 다운로드
• 📥 불러오기 — JSON 파일 → 폼 자동 입력
• 💾 전체 백업 — 모든 데이터를 JSON 파일로 저장
• 📂 전체 복원 — 백업 파일로 전체 복원
• 🖨️ 인쇄 — 미리보기 인쇄 / PDF 저장
• 📊 정산 — 정산 보고서 페이지 이동
• 🔧 계산기 — 현장 계산기 모달 (수목중량·면적·근분표)
• 전체 초기화 — 모든 데이터 삭제 (되돌릴 수 없음)
