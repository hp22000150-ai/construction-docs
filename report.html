기간 / 공사명 필터
시작일·종료일을 설정하고 공사명을 선택하면 해당 조건의 일보 데이터만 불러옵니다.
공사명을 선택하지 않으면 전체 현장을 합산합니다.

인력 정산
기간 내 일보에서 성명별 공수를 자동 합산합니다.
단가 칸에 금액을 입력하면 합계 = 공수 × 단가가 자동 계산됩니다.

장비 정산
기간 내 일보에서 장비명별 투입 일수를 자동 합산합니다.
단가 입력 → 합계 자동 계산.

합계
인력 소계 + 장비 소계를 합산하여 총액을 표시합니다.

💾 단가 저장
입력한 단가를 저장합니다. 다음에 정산 페이지를 열면 저장된 단가가 자동으로 불러와집니다.
저장 버튼을 누르지 않으면 단가가 유지되지 않습니다.

PDF 인쇄
인쇄 버튼을 누르면 헤더·필터 영역은 숨겨지고 정산 결과만 인쇄됩니다.
