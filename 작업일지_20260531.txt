[ 신규 기능 ]
- 인력 공수 직접 입력 지원 (0.5/1.0 선택 → 숫자 직접 입력 가능)
- 장비 투입 금액(원) 직접 입력칸 추가 (PC/모바일 공통)
  · 금액 입력 시 미리보기 비고/금액 칸에 표시 (천단위 콤마)
  · 정산 시 단가 계산 대신 직접 입력 금액 사용
- 장비 부가세 10% 선택 옵션 추가 (장비투입정산 제목 옆)
- 정산보고서 엑셀(.xlsx) 내보내기 추가 (인력/장비/합계 시트)
- 기간별 데이터 전송 기능 (모바일 기본설정 → 데이터 전송)
  · 기간/월/전체 선택, 공사명 필터, JSON 파일 전송
- 정산 다중 파일 불러오기 지원 (Ctrl+클릭으로 여러 파일 선택)
- 정산 통합 파일로 저장 기능 (여러 파일 → 하나로 합치기)
- Electron data 폴더 자동 저장/불러오기 지원
- 모바일 웹 뷰 최대 480px 중앙 고정 레이아웃 (PC 브라우저에서 폰처럼 표시)
- 정산 데이터 없을 때 날짜/정산하기 비활성화, 불러오기 후 활성화
- 미리보기 A4 사이즈 종이 형태로 표시 (회색 배경 + 흰 종이 + 그림자)
- 미리보기 금액·수량 천단위 콤마 표시
